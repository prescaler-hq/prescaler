# Prescaler

Prescaler is a desktop IDE for firmware development. Edit, build, flash,
and debug in one app.

**This repository does not contain the IDE's source code.** Prescaler is
closed source. This repo exists so we can track bugs and feature requests
in the open, the same way many closed-source developer tools do.

## Report a bug or request a feature

Use [Issues](../../issues) on this repo. Include your OS, Prescaler
version, and target MCU where relevant, it helps us reproduce faster.

Requesting a new MCU target? Say so directly, we track hardware requests
here too.
